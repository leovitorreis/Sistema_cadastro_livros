# 📚 Sistema de Cadastro de Livros

Este projeto foi desenvolvido como parte da atividade da Unidade 2 da disciplina de Programação em Python. O objetivo é criar um sistema simples de cadastro de livros, utilizando listas, dicionários, funções e a biblioteca Matplotlib para gerar gráficos.

## 💡 Funcionalidades

- Adicionar livros com título, autor e gênero
- Listar todos os livros cadastrados
- Gerar um gráfico de barras com a quantidade de livros por gênero

## 🧠 Lógica Utilizada

Os livros são armazenados em uma lista de dicionários. Cada dicionário representa um livro com três informações: `titulo`, `autor` e `genero`. O programa é dividido em funções para organizar melhor o código e facilitar a reutilização. A função principal exibe um menu interativo que permite ao usuário escolher o que deseja fazer.

Para gerar o gráfico, o programa conta quantos livros existem de cada gênero e utiliza a biblioteca Matplotlib para exibir os dados em um gráfico de barras. Os nomes dos gêneros são rotacionados para melhorar a visualização.

## 📊 Exemplo de Gráfico

O gráfico mostra a distribuição dos livros por gênero, facilitando a análise visual da coleção cadastrada. Gêneros com nomes longos são rotacionados para evitar sobreposição.

A atividade permitiu aplicar conceitos fundamentais de Python e explorar o uso de bibliotecas externas para visualização de dados. O projeto mostrou como a programação pode ser usada para resolver problemas reais de forma prática e organizada.

## 🚀 Como Executar

1. Instale o Matplotlib (se ainda não tiver):
2. pip install matplotlib
3. Execute o arquivo `sistema.py` em um ambiente local (VS Code, terminal, etc.)

> ⚠️ No Google Colab, o menu interativo com `input()` pode não funcionar corretamente. Recomenda-se rodar o código localmente para melhor experiência.
